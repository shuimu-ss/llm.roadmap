1在 GitHub 网页上新建一个空仓库

如果 GitHub 打不开或很慢，可以改用 Gitee（国内直连实测通）：在 gitee.com 新建同名公开仓库，后面把地址换成 gitee 的即可，脚本两处都支持。简历上 Gitee 链接同样能用，但国际认可度低于 GitHub。
2生成一个 token（当密码用）
  • GitHub：头像 → Settings → 左侧最下 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)

安全：token 等于账号密码。它只写进本地的 push_config.json，该文件已被 .gitignore 排除，绝不会上传。用完建议去 GitHub 把 token 删掉（Revoke）。别发在聊天、别贴截图里。
